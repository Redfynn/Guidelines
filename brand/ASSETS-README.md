# Assets

- `logos/` four logo PNGs. The three wordmark files (Primary-Black, Primary-BlackRed, Secondary-BlackRed) have white backgrounds baked in, so use them on white only. `Icon-Black` is transparent.
- `gradients/` six noisy red-orange gradient crops from section 2.5 of the 2024 brand guide. Use as backgrounds with black text on top. Resolution is modest, so add the grain layer and use them for panels or heroes rather than full-screen print.
- `redfynn-web.css` tested stylesheet. See `../references/web-implementation.md`.

## Not included, ask the brand owner for these
- TWK Everett font files (licensed) and the Feeling Passionate script.
- Vector (SVG or AI) logos.
- Reversed logos for dark, red and gradient backgrounds, with transparent backgrounds. Section 2.2 of the guide shows them but no files were supplied.
- Full-resolution gradient artwork and the animated gradients.
